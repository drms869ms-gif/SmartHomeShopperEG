# SmartHomeShopperEG — برنامج بوت أسعار البقالة

بوت تيليجرام يبحث **عند الطلب فقط** عن أسعار منتجات البقالة والألبان والسوبر ماركت في مصر/القاهرة، ويعرض مصادر وروابط النتائج. لا توجد تقارير يومية أو تشغيل مجدول.

## ما الذي يفعله؟
- يستقبل اسم المنتج في تيليجرام.
- يبحث على الويب باستخدام Serper، مع توجيه البحث إلى مصر وباللغة العربية.
- يعرض عنوان النتيجة والمقتطف والمصدر والرابط.
- لا يخترع سعرًا إذا لم يظهر سعر واضح.
- يوضح أن نتائج البحث ليست تأكيدًا مباشرًا من المتجر، وأن الأسعار قد تختلف حسب الفرع والعروض.
- يسمح افتراضيًا فقط للمحادثة ذات المعرّف `457342847`.

## ما المطلوب لتشغيله 24/7؟
يلزم استضافة تعمل باستمرار، مثل VPS أو خدمة استضافة تدعم Docker/Worker دائمًا. لا يكفي تشغيل الكود داخل محادثة ChatGPT.

### 1) المفاتيح المطلوبة
1. **Telegram Bot Token**: افتح محادثة BotFather في تيليجرام، واختر البوت `@SmartHomeShopperEG_bot`، ثم اعرض/انسخ الـ API Token. لا ترسله في مجموعة عامة ولا تضعه في الكود.
2. **Serper API Key**: انسخ المفتاح من لوحة حساب Serper. راقب الرصيد لأن كل عملية بحث تستهلك رصيدًا.

أضف القيم في متغيرات البيئة لدى الاستضافة:
- `TELEGRAM_BOT_TOKEN`
- `SERPER_API_KEY`
- `ALLOWED_CHAT_ID=457342847`

لا ترفع ملف `.env` أو المفاتيح إلى GitHub.

### 2) التشغيل المحلي للاختبار
يتطلب Python 3.11 أو أحدث.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

انسخ `.env.example` إلى `.env` واملأ المفاتيح. ثم شغّل المتغيرات في الطرفية أو استخدم أداة تحميل env، وبعدها:

```bash
python bot.py
```

هذا الملف لا يحمّل `.env` تلقائيًا؛ على Windows PowerShell يمكنك ضبط المتغيرات للجلسة هكذا:

```powershell
$env:TELEGRAM_BOT_TOKEN="ضع_التوكن"
$env:SERPER_API_KEY="ضع_المفتاح"
$env:ALLOWED_CHAT_ID="457342847"
python bot.py
```

وفي macOS/Linux:

```bash
export TELEGRAM_BOT_TOKEN="ضع_التوكن"
export SERPER_API_KEY="ضع_المفتاح"
export ALLOWED_CHAT_ID="457342847"
python bot.py
```

### 3) تشغيله على استضافة Docker
ارفع مجلد المشروع إلى خادمك أو مستودع خاص، ثم ابنِ الصورة:

```bash
docker build -t smarthomeshopper-eg .
docker run -d --restart unless-stopped \
  --name smarthomeshopper-eg \
  -e TELEGRAM_BOT_TOKEN="ضع_التوكن" \
  -e SERPER_API_KEY="ضع_المفتاح" \
  -e ALLOWED_CHAT_ID="457342847" \
  smarthomeshopper-eg
```

استخدم واجهة الاستضافة لإضافة Environment Variables بدل كتابة المفاتيح في سجل أو ملف عام.

## مهم قبل التشغيل
- يجب أن تكون هذه الخدمة هي المستهلك الوحيد لتحديثات البوت. لا تشغّل نسخة ثانية من البرنامج ولا تستخدم `getUpdates` في الوقت نفسه؛ تيليجرام يسمح بمستهلك واحد للتحديثات.
- البرنامج يحذف Webhook عند بدء التشغيل لكي يستخدم Long Polling. إذا كان هناك نظام آخر يستخدم Webhook لهذا البوت، لا تشغّل هذا البرنامج قبل التأكد من أنك تريد استبداله.
- إذا لم يكن رصيد Serper متاحًا، سيرسل البوت رسالة خطأ بدل اختلاق نتائج.
- قد تعرض محركات البحث أسعارًا قديمة أو غير مكتملة. النسخة الحالية تعرض مصدر كل نتيجة وتحذيرًا واضحًا، لكنها لا تستطيع تأكيد السعر الفعلي عند الكاشير.
- بيانات الدخول لا تُضمَّن في الحزمة. لا تشارك التوكن أو المفتاح معي أو مع أي شخص.

## اختبار سريع
1. شغّل البرنامج على الاستضافة.
2. افتح `@SmartHomeShopperEG_bot` وأرسل `/start`.
3. أرسل مثلًا: `أرخص سعر لبن المراعي كامل الدسم 1 لتر`.
4. إذا لم يصل رد، راجع سجلات الخدمة ومتغيرات البيئة ورصيد Serper.
